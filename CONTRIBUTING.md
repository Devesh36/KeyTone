# Contributing to Keytone

Thanks for helping make keyboards more expressive.

1. Discuss substantial behavior changes in an issue first.
2. Keep each pull request focused and add tests for engine behavior.
3. Run the complete checks listed in the README.
4. Document user-visible behavior and any new sound-pack fields.
5. Confirm that contributed audio is redistributable and include its license and source.

Privacy and real-time safety are release blockers. Contributions must not persist or transmit keyboard events, add telemetry, perform callback disk I/O, introduce callback locks, or log typed key sequences.

By participating, you agree to the [Code of Conduct](CODE_OF_CONDUCT.md). Contributions are licensed under MIT.
