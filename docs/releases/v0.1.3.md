# Keytone v0.1.3

Mechanical switches come to the sound-pack library.

## What's new

- Original, shaded switch illustrations replace the wave icons, with pack-specific colors and a fallback for imported packs.
- Hover to move the stem; click the switch or Preview button to hear the pack and see a press animation.
- Keyboard-accessible preview buttons and reduced-motion support.
- Preview failures now appear in the app instead of failing silently.
- Five component regression tests, also run in CI.

This release includes the keyboard-listener fixes from v0.1.2. The audio engine and sound assets are unchanged from that release.

## Downloads and updates

Choose the installer below for your system: universal `.dmg` for Apple Silicon or Intel Macs, `.exe` / `.msi` for Windows, or `.AppImage` / `.deb` / `.rpm` for Linux, where provided.

Keytone does **not** update automatically yet. Quit the old app completely, download the new installer, and replace the installed app. Local settings are stored separately and should be retained.

## macOS installation and keyboard access

This release is ad-hoc signed, not Developer ID signed or notarized. If macOS blocks opening a copy you downloaded from this repository, go to **System Settings → Privacy & Security → Open Anyway**, then confirm. This only permits launching the app; keyboard access is a separate permission.

Install Keytone in **Applications** before granting **Privacy & Security → Input Monitoring** access, then restart Keytone.

**Already enabled, but the listener is disconnected after an update?**

1. Quit Keytone through its menu-bar **Quit** command, not just the window's close button.
2. In **Input Monitoring**, select the old **Keytone** entry and click **−** to remove it.
3. Click **+**, choose **Applications → Keytone**, and turn access on.
4. Launch Keytone again from Applications.

This refreshes permission for the installed build. Do not disable Gatekeeper or other system protections. If **Test sound** works but typing still does not, check the listener status in Keytone's Settings and report the issue with your macOS version—never include typed text or keyboard history.
